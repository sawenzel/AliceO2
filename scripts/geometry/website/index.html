What this is

    
A CAD part converted for simulation can be carried into the geometry in three ways: as native CSG
      primitives, as its real trimmed analytic surfaces, or as a triangle mesh. This page reads the second
      one — the surfaces_*.bin sidecar — and renders it by intersecting rays with the
      actual planes, cylinders, cones, spheres and tori, trimmed by their real boundary wires. Nothing here is
      tessellated: a cylinder shades smoothly because it is a cylinder.

    
Everything is served from this directory. There is no CDN, no external request and no server-side
      component; the raytracer is JavaScript in a worker.

    
Provenance of the maths

    
The kernels are a port of Detectors/Base/src/BoundedSurface.h, and the sidecar parser
      mirrors Detectors/Base/src/O2SurfaceSolidIO.cxx record for record. See
      scripts/geometry/website/README.md for what is supported, what is approximated and how the
      self-check numbers were obtained.
